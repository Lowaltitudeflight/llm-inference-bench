## 正文怎么贴（关键）

建议用**文件导入**而不是直接粘贴：

1. 打开 https://zhuanlan.zhihu.com/write
2. 编辑器工具栏右上角找到 **「导入文档」**（图标通常是一个带箭头的文件）
3. 直接把 `docs/article-llm-bench-5-pitfalls.md` 拖进去
4. 知乎会解析 Markdown 并转成富文本
5. **导入后逐段检查**（见下方检查清单）

**如果找不到导入按钮**，退而求其次：

- 复制 `docs/article-zhihu-plain.txt` 全文直接粘贴（推荐，失败率最低）

**不要**直接复制 `.md` 文件里的源码粘进知乎。

## 表单填写

### 标题

知乎标题可以稍长，且偏「问题式」更容易被点：

```
我把 8 卡 72B 的压测经验写成了开源工具：LLM 推理压测里最容易写错的 5 件事
```

备选：

```
LLM 推理压测里最容易写错的 5 件事（附开源工具）
```

```
为什么你的 LLM 压测数据可能是错的？聊聊 5 个容易写错的指标口径
```

### 话题（相当于掘金的标签）

知乎最多加 **5 个话题**，按顺序：

```
LLM
vLLM
性能优化
Python
开源
```

> 说明：知乎的话题库比掘金粗，「大语言模型」这个官方话题优先选它而不是「LLM」，
> 如果搜不到再退回「LLM」。

### 摘要 / 开头导语

知乎文章开头一段会显示在信息流里，建议用这段：

```
部署完大模型之后，怎么证明它跑得好？客户会问「能扛多少并发」「体感快不快」
「换量化能省多少显存」——而回答这些问题时，很多压测脚本的指标算法其实是错的，
而且不报错，只是安静地给你一个错误的数。本文拆解 5 个最容易写错的口径。
```

## 发布前检查清单

知乎的导入解析比掘金弱，**这几处最容易坏**：

| 检查项 | 怎么确认 | 坏了怎么办 |
| --- | --- | --- |
| **表格** | 逐个数一下表格行列对不对 | 知乎导入常丢表格。坏了就用截图代替（把 Markdown 表格截图贴上） |
| **代码块** | 看有没有语法高亮、缩进是否保留 | 手动选中代码，点工具栏「代码块」按钮重新设置 |
| **ASCII 架构图** | 看是否还对齐 | 知乎会按比例字体渲染，可能错位。坏了就换成截图 |
| **文中链接** | 点一下确认能打开 | 重新粘贴 URL |
| **加粗 / 斜体** | 看 `**` 是否变成了加粗 | 说明没用导入功能，得换方式重贴 |

> 我的建议：**架构图和时间轴那两段 ASCII 图，直接截图贴**。
> 知乎不是等宽字体环境，粘进去基本会错位，截图反而更清晰。

## 发布后的动作

**1. 回答相关问题**

知乎的流量大头在**回答**而不是文章。文章发完后：

- 搜 `LLM 推理性能`、`vLLM 部署`、`大模型压测`、`TTFT`
- 找关注度高、回答数不多的问题
- 写一段有针对性的回答（不要只贴链接），末尾自然带一句「完整代码和推导在我的文章里」

**这一步比发文章本身更有效。** 知乎回答的长尾搜索流量很持久。

**2. 简历里放链接**

```
技术文章（掘金）：https://juejin.cn/post/xxxxx
技术文章（知乎）：https://zhuanlan.zhihu.com/p/xxxxx
```

**3. 不要去刷赞同**

知乎有反作弊。短时间内异常点赞会被折叠，甚至降权。让它自然增长。
