## 7. 结论与建议

### 7.1 关键结论

- 吞吐最优：**ollama**（`qwen2.5:7b`，q4_K_M），峰值 **30.8 tokens/s**，出现在并发 8。

### 7.2 选型建议

- **交互式场景（对首字速度敏感）**：优先 ollama（q4_K_M），最低 TTFT 168.81 ms。问答、代码补全类应用建议把并发控制在 1 附近，超过后 TTFT 会随排队显著上升。
- **离线批处理场景（吞吐优先）**：把并发开到 **8**，此时 ollama 吞吐达到峰值。再往上加压不会提升吞吐，只会拉长单请求时间。
- **显存受限场景**：建议补测 AWQ/INT8 配置以获得「每 GiB 显存吞吐」对比，量化通常能把显存压到 FP16 的 25%~50%。

### 7.3 复现方式
```bash
# 单引擎压测
python scripts/run_bench.py --engine vllm

# 多引擎对比 + 出报告
python scripts/run_bench.py --engine vllm,ollama --report
```
